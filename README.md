<h1>Learning App</h1>

This is currently a bare bones learning app for math, with problems getting naturally harder as you get them right and easier as you get them wrong.
<h2>Download Instructions</h2>
<ol>
  <li>In order to download, click the green "CODE" button, click the "download zip" button that appears at the bottom.</li>
  <li>This will download a zip file with all the required files for the app.</li>
  <li>Right click the zip file and extract all the files.</li>
  <li>When extraction is done, open the folder, and press the file named "Learning_App.exe". This is the app.</li>
  <li>That's all! No other installations required. Enjoy!</li>
</ol>
